# PC-GAMER-CLOUD-# 🎮 PC GAMER CLOUD

PC gamer na nuvem com acesso pelo celular Android usando Moonlight e Sunshine.

## 🎯 Objetivo
Preparar um computador Windows para transmitir jogos ao celular.

## 💻 Hardware desejado
- RAM: 16 GB
- GPU: ?
- SSD: 250 GB
- CPU: 8 vCPU
- Sistema: Windows 11

## 📱 Como funciona
1. Sunshine roda no computador servidor.
2. Moonlight roda no celular.
3. Os dispositivos se conectam por uma rede privada.
4. Você transmite os jogos para o celular.

## ⚠️ IMPORTANTE
Este projeto não cria uma máquina virtual nem fornece uma RTX 3060 gratuitamente.

O hardware depende do servidor utilizado.

## 🛠️ Tecnologias
- Windows
- Sunshine
- Moonlight
- PowerShell
- Tailscale
